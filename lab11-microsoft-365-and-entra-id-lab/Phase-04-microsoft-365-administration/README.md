# Phase 04 - Final Practical Assessment

## Overview

This phase focuses on applying the knowledge and practical skills developed throughout Lab 11 – Microsoft Entra ID Administration.

The objective is to simulate realistic Tier 1 Help Desk scenarios involving cloud user administration, security groups, password resets, Multi-Factor Authentication (MFA), and administrative permissions.

The assessment uses the EduIT Training Lab Microsoft 365 Business Premium tenant.

All scenarios are performed from the perspective of a Tier 1 Help Desk technician, with an emphasis on troubleshooting, appropriate administration, and the principle of least privilege.

## Objectives

- Apply Microsoft Entra ID administration skills in realistic Help Desk scenarios.
- Create and configure cloud user accounts.
- Create security groups and manage group membership.
- Perform cloud password resets.
- Troubleshoot Microsoft Authenticator and MFA issues.
- Understand and use Temporary Access Pass (TAP).
- Identify appropriate administrative roles and permissions.
- Apply the principle of least privilege.
- Develop confidence handling common Tier 1 Help Desk requests.

## Structure

### Final Practical Assessment

Completed five simulated Help Desk tickets covering the main administration topics explored throughout Lab 11.

**Ticket 01 – New Employee Onboarding**

Created a new cloud-only user account:

| User | Job Title | Department | Employee ID |
|---|---|---|---|
| Michael Torres | Sales Representative | Sales | EMP003 |

Key activities:
- Created the new cloud user in Microsoft Entra ID.
- Configured the employee's account properties.
- Set the job title, department, and employee ID.
- Verified successful account creation.

**Ticket 02 – Security Group Management**

Created a new security group:

| Group | Membership Type | Member |
|---|---|---|
| Sales Group | Assigned | Michael Torres |

Key activities:
- Checked the existing security groups.
- Created the Sales Group.
- Configured the group description.
- Added Michael Torres as a member.
- Verified group membership.
- Reinforced the difference between user department attributes and security group membership.

**Ticket 03 – Password Reset**

Simulated a Tier 1 Help Desk password-reset request for Sarah Johnson.

Key activities:
- Identified the user's password problem.
- Reset the cloud user's password.
- Generated a temporary password.
- Enabled the requirement to change the password at the next sign-in.
- Reviewed basic password-reset procedures.

**Ticket 04 – MFA Troubleshooting**

Simulated an authentication problem involving John Smith and Microsoft Authenticator.

The user had replaced his phone and could no longer receive authentication approval notifications.

Key activities:
- Gathered information about the authentication problem.
- Identified the recent phone replacement as a possible cause.
- Inspected the user's registered authentication methods.
- Identified that no usable authentication methods were available.
- Explored the Temporary Access Pass (TAP) recovery process.
- Generated a one-time Temporary Access Pass with a one-hour lifetime.
- Simulated securely providing the TAP to the user.
- Completed the simulated recovery and registration of Microsoft Authenticator on the new phone.
- Verified successful MFA authentication.

**Ticket 05 – Administrative Roles and Permissions**

Simulated a request from Sarah Johnson to manage the HR security group.

Key activities:
- Located Microsoft Entra administrative roles.
- Identified Groups Administrator as the appropriate administrative role for managing groups across the tenant.
- Reviewed the role's purpose and permissions.
- Applied the principle of least privilege.
- Considered group ownership as a more limited alternative when access is only required for a specific group.

No additional administrative roles were assigned during this assessment.
