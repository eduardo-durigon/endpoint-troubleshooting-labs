# Phase 1 – Microsoft 365 Personal Environment

**Status: Completed**

## Overview

In this phase, I configured and explored a Microsoft 365 Personal environment to become familiar with Microsoft's desktop applications, Outlook, and OneDrive synchronization.

The objective was to understand the end-user experience before moving on to Microsoft 365 Business administration and cloud identity management.

## Environment

- **Device:** Lenovo – EDU-LAB-CL02
- **Operating System:** Windows 11 Pro
- **Microsoft 365 Plan:** Microsoft 365 Family
- **Applications:** Microsoft 365 desktop applications (64-bit)

## Completed Tasks

### 1. Microsoft 365 Installation

- Installed the 64-bit Microsoft 365 desktop applications.
- Signed in using a personal Microsoft account.
- Verified access to the installed applications.

### 2. Outlook Configuration

- Opened and configured the new Outlook application.
- Signed in using a personal Microsoft account.
- Added multiple personal email accounts.
- Sent and received test emails.
- Investigated an issue where the Send button was unavailable because the recipient address was not recognized.

### 3. OneDrive Configuration

- Signed in to OneDrive using a personal Microsoft account.
- Created a dedicated folder named `IT-Lab-OneDrive`.
- Created a test file named `Sync-Test.txt`.
- Verified synchronization from the local computer to OneDrive.
- Verified synchronization from OneDrive back to the local computer.
- Deliberately left Desktop and Documents backup disabled.

## Skills Practised

- Microsoft 365 desktop application installation.
- Personal Microsoft account authentication.
- Basic Outlook configuration.
- Adding and managing multiple email accounts.
- Sending and receiving test emails.
- Basic email troubleshooting.
- OneDrive configuration and synchronization.
- Understanding local-to-cloud and cloud-to-local file synchronization.

## Outcome

Successfully installed and configured Microsoft 365 Personal applications, tested basic Outlook functionality, and verified OneDrive synchronization.

This phase provided practical familiarity with Microsoft 365 from an end-user perspective before moving into business administration.
