# Lab 11 – Microsoft 365 & Entra ID Administration

## Overview

This project focuses on developing practical Microsoft 365 and Microsoft Entra ID administration skills for entry-level IT Support / Help Desk roles.

The objective is to build and manage a small-business cloud environment, practise everyday administrative tasks, and troubleshoot realistic Microsoft 365 support scenarios.

The project will cover cloud identity management, authentication, Outlook, Exchange Online, OneDrive, Microsoft Teams, SharePoint and common end-user issues.

## Objectives

- Understand Microsoft Entra ID and cloud identity management.
- Create and manage cloud users and security groups.
- Understand authentication and MFA.
- Navigate Microsoft 365 Admin Center.
- Understand Microsoft 365 licensing and administrative roles.
- Configure and troubleshoot Outlook.
- Understand Exchange Online mailbox administration.
- Manage OneDrive synchronization and file sharing.
- Understand basic Teams and SharePoint administration.
- Practise realistic Tier 1 Help Desk troubleshooting scenarios.
