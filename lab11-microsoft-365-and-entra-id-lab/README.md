# Lab 11 – Microsoft 365 & Entra ID Administration

## Overview

This project focuses on developing practical Microsoft 365 and Microsoft Entra ID administration skills for entry-level IT Support / Help Desk roles.

The objective is to build and manage a small-business cloud environment, practise everyday administrative tasks, and understand how modern organizations manage cloud identities, authentication, email, collaboration and access to resources.

The project builds upon the traditional Active Directory experience developed in Lab 10 and introduces cloud-based identity and Microsoft 365 administration.

## Objectives

- Understand Microsoft Entra ID and cloud identity management.
- Understand the differences between traditional Active Directory and cloud identity.
- Create and manage cloud users and security groups.
- Understand authentication, MFA and administrative roles.
- Navigate Microsoft 365 Admin Center.
- Understand Microsoft 365 licensing and service administration.
- Explore Exchange Online and mailbox administration.
- Understand shared mailboxes and distribution lists.
- Explore Microsoft Teams and SharePoint administration.
- Manage OneDrive settings, storage and sharing.
- Understand how Microsoft 365 services integrate with one another.

The focus is practical administrative competence and understanding how a small business uses Microsoft 365, rather than simply collecting certifications or memorizing features.
