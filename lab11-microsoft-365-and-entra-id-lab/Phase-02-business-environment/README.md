# Phase 2 – Microsoft 365 Business Environment

**Status: Completed**

## Overview

In this phase, I established a Microsoft 365 Business environment to practise cloud administration and prepare for entry-level IT Support / Help Desk responsibilities.

The objective was to create a business tenant, configure an administrator account, access the Microsoft 365 Admin Center, and verify the subscription and licensing environment.
